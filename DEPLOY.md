# 🚀 ENERED — Deploy guide (Netlify + Render + Atlas + R2)

> Free-tier total: **$0/mo**.  Paid only if you want to remove Render's cold start (~$7/mo).

## Architecture

```
User Browser → Netlify (React) → Render (FastAPI) → MongoDB Atlas (data)
                                                  → Cloudflare R2 (PDFs/QRs/XML)
                                                  → Google Sheets API (read-only)
```

## Prerequisites

You should already have:

- [x] GitHub repo with this code pushed.
- [x] MongoDB Atlas cluster (M0 free) — connection string handy.
- [x] Cloudflare R2 bucket `enered-uploads` + API token (Access Key + Secret).
- [x] Google Sheets service-account JSON (the contents, not the file).

---

## 1. Deploy backend to Render

1. Go to https://dashboard.render.com → **New +** → **Blueprint**.
2. Connect your GitHub repo.  Render reads `render.yaml` automatically.
3. After it scaffolds the service, open **Environment** and fill in:

   | Variable | Value |
   |---|---|
   | `MONGO_URL` | `mongodb+srv://USER:PASS@cluster0.xxxx.mongodb.net/?appName=Cluster0` |
   | `DB_NAME` | `enered_prod` |
   | `JWT_SECRET` | (auto-generated by Render) |
   | `ADMIN_EMAIL` | `admin@enered.com` |
   | `ADMIN_PASSWORD` | (a strong password — save it!) |
   | `CORS_ORIGINS` | `https://YOUR-SITE.netlify.app` |
   | `FRONTEND_URL` | `https://YOUR-SITE.netlify.app` |
   | `R2_ACCESS_KEY_ID` | from Cloudflare R2 |
   | `R2_SECRET_ACCESS_KEY` | from Cloudflare R2 |
   | `R2_ENDPOINT` | `https://YOUR-ACCOUNT-ID.r2.cloudflarestorage.com` |
   | `R2_BUCKET` | `enered-uploads` |
   | `GOOGLE_SHEETS_CREDENTIALS_JSON` | paste **whole JSON** as one string |
   | `GOOGLE_SHEETS_ID` | (already set in render.yaml) |
   | `GOOGLE_SHEETS_TAB` | `Hoja 1` |

4. Click **Manual Deploy → Deploy latest commit**.  Wait ~5 min.
5. Verify: open `https://enered-api.onrender.com/api/health`.
   Expected: `{"status":"ok","mongo":"ok","storage_backend":"r2",...}`.

## 2. Deploy frontend to Netlify

1. Go to https://app.netlify.com → **Add new site → Import from Git**.
2. Select the same repo.  Netlify reads `netlify.toml` automatically.
3. Before clicking **Deploy site**, expand **Add environment variables**:

   | Variable | Value |
   |---|---|
   | `REACT_APP_BACKEND_URL` | `https://enered-api.onrender.com` |

4. **Deploy site**.  Wait ~3 min.
5. After it's live, **copy the URL** (e.g. `https://random-name-12345.netlify.app`).
6. Go back to Render → set `CORS_ORIGINS` and `FRONTEND_URL` to that URL
   (overwrite the placeholder), then **Manual Deploy → Clear cache & deploy**.

## 3. Migrate existing data

From your local dev machine (where `backend/uploads/` and the local MongoDB live):

```bash
# (1) Copy DB → Atlas
python scripts/migrate_mongo_to_atlas.py \
  --src   'mongodb://localhost:27017/test_database' \
  --dest 'mongodb+srv://USER:PASS@cluster0.xxxx.mongodb.net/enered_prod' \
  --replace

# (2) Copy uploads/ → R2  (uses backend/.env if present)
python scripts/migrate_uploads_to_r2.py
```

## 4. Verify

- Open the Netlify URL.
- Log in as `admin@enered.com` with the password you set.
- Dashboard should show real numbers (from Atlas).
- Click any factura → **Descargar PDF** → file should download (proxied from R2).
- `/api/admin/sheets/sync` should still work (now reading creds from env var).

## 5. (Optional) Custom domain

- Netlify → site settings → Domain → add `app.enered.pe`
- Render → settings → Custom Domains → add `api.enered.pe`
- Update `CORS_ORIGINS` on Render & `REACT_APP_BACKEND_URL` on Netlify accordingly.

## 6. Keep Render awake (avoid 30s cold start)

Render's free plan sleeps after 15 min idle.  Two options:

- **Free**: create a UptimeRobot monitor that pings `/api/health` every 5 min.
- **Paid**: upgrade Render plan to **Starter** ($7/mo) — always on, faster CPU.
